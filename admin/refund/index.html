Issue refund

Full SumUp refund + cancel: emails the customer, cancels the calendar entry, and marks tracking cancelled. For partial refunds or refund-without-cancel, use Cancel / Refund on the owner dashboard.

Refund the full remaining balance to the original payment method for booking … and cancel the journey?

Use the SumUp transaction code shown on the customer invoice or in your driver dashboard. Refunds return to the customer's original card via SumUp. Unlocking the page is not enough — you must re-enter the owner key immediately before each refund.
