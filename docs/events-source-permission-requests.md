# Event data permission requests — DRAFTS (do not send without owner approval)

Status: drafts only. Nothing has been sent. Fill in the bracketed fields before sending.
Contact addresses marked *unverified* must be confirmed on the organisation's own website first.

Background (Phase 0, checked 6 Nov 2026):
- Ticketmaster Discovery API terms say users must not "derive revenues from the use or provision of the Ticketmaster API … except as set forth".
- Skiddle API: "non-commercial use only. Any commercial use must be first approved in writing by emailing api@skiddle.com".
- Visit Belfast / Discover NI terms forbid commercial reuse without a licence.
- Belfast Waterfront / Ulster Hall / Grand Opera House pages publish schema.org event data, but give no explicit permission for reuse.

What we would show, in every case: event title, date, start time, venue, category and a link back to the official event or ticket page. No ticket sales, no copied descriptions, no images unless the rights holder agrees, and a clear statement that we are an independent taxi company, not the organiser or a ticket seller.
