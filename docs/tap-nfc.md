# Tap & Scan — NFC / QR headrest

Permanent public URL (NFC chip and QR must match exactly):

`https://www.myairporttaxini.co.uk/tap`

## QR assets

Generated by `node scripts/generate-tap-qr.mjs`:

- `public/tap/qr.svg` — vector, black on white, ECC H, quiet zone 4
- `public/tap/qr.png` — 1200×1200 PNG for print
- `public/tap/headrest-plate-150x100.svg` — 150 × 100 mm landscape plate artwork
- `public/tap/headrest-plate-150x100-print.svg` — plate with logo + QR embedded (preferred for print)
- `public/tap/headrest-plate-150x100-preview.png` — screen preview of the print plate

Print the plate at **100% scale** (no “fit to page”). Keep the white quiet zone around the QR unobstructed. Await owner approval before bulk professional print.

## Program an NTAG213 or NTAG215

No subscription service is required. Use any NDEF writer app (e.g. NFC Tools) on a phone that supports NFC writing:

1. Erase / format the tag if it was used before.
2. Add an **NDEF URI** record (not plain text).
3. URI: `https://www.myairporttaxini.co.uk/tap`
4. Write to the tag and lock it (optional but recommended for headrest plates).
5. Test with an iPhone and an Android phone — both should open the same page as the QR code.

NTAG213 has enough memory for this short HTTPS URL. NTAG215 is fine if already stocked.
